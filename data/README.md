# Public dataset included for reproducibility

The original UCI Adult download and its extracted data files are included in `raw/adult/` so this project can be reproduced without finding a separate dataset.

**Attribution:** Becker, B. & Kohavi, R. (1996). *Adult* [Dataset]. UCI Machine Learning Repository. DOI: https://doi.org/10.24432/C5XW20 . Provider: https://archive.ics.uci.edu/dataset/2/adult .

**License:** Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/ . This is freely reusable with attribution, not copyright-free. The source files are unmodified; exact download hashes and retrieval time are in `records/adult_dataset.json`.

Analysis scripts deduplicate records, separate data roles and create controlled sampling interventions. Those transformations do not represent natural chronological drift. Original source files do not include visitor-uploaded website data.
