# Figure specification prepared in this task

The separately referenced original FIGURE_SPEC.md was unavailable. This specification is new.

Each empirical plot must come from completed, saved run JSON files whose hashes match their run manifest. Each figure has a CSV, JSON manifest, vector PDF/SVG, and 300 dpi PNG. The manifest identifies the config, input run manifest, plot script, software environment, and AI role. Seeds and exact test counts live in raw results/configs. A combined PDF and local HTML gallery are generated by the same command.

Default matplotlib colors, distinct marker/line styles, explicit denominators and uncertainty, readable one-chart figures, and full zero-to-one probability axes are used. No smoothing or selective seed picking. Figures labelled analytical are mathematical planning/teaching examples and must not be described as measured experimental evidence.

The source CSV for a delay distribution includes uncertainty even where bars only show proportions. Mean PSI intervals are uncertainty in the mean across runs, not a PSI-based hypothesis test. A marked 0.1 threshold is practical context, not a significance threshold.

Reuse captions and retain the synthetic/semi-synthetic/analytical description when moving a chart into a paper or presentation. Dataset attribution must accompany Adult results. AI-assisted code and plotting are disclosed in the gallery and manifests.
